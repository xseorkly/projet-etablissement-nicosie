# Projet d'établissement 2026-2030 — Lycée franco-chypriote de Nicosie

Site collaboratif **indépendant** (aucun lien avec un autre site) : site statique (GitHub Pages) + Google Apps Script + Google Sheet + Google Drive.

## Fonctionnement
- **Travail** : le groupe choisit son axe (4 axes) puis son groupe (1 à 5), indique les personnes présentes (prénom, nom ou pseudonyme), choisit un **code de groupe** (4 caractères min.), puis suit la trame en 6 points : Diagnostic, Objectif général, Sous-objectifs, Actions, Indicateurs, Critères d'évaluation, avec questions pour guider et pistes par axe.
- **Minuteur** de 45 minutes par séquence de travail (démarrer / pause / remise à zéro, alertes à 5 minutes et à la fin, sans blocage de l'écriture).
- **Confidentialité** : un groupe ne voit jamais le travail des autres (contrôlé côté serveur grâce au code du groupe). Chaque groupe peut envoyer son PDF dans le Drive ou l'imprimer.
- **Administration** (code administrateur) : toutes les contributions par axe et par point de la trame, liste des groupes (codes, suppression), export PDF + texte Markdown de tout le projet ou d'un axe, avec consigne prête pour une IA, rangés dans le dossier « Exports » du Drive.

## Fichiers
`index.html`, `projet.js`, `projet.css`, `base.css`, `assets/` (site) — `Code.gs` (Apps Script) — `CONFIGURATION.md` (mise en route).
